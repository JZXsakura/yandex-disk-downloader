# 🌸 Yandex Disk Downloader

**Навайбкодил расширение для скачивания файлов и целых папок с Яндекс Диска.**

После точных попаданий по датацентрам яндекса кнопка "скачать все" перестала существовать. А так как я монтажер, который вынужден качать по 50-100 роликов в день я был в шоке)) 
Расширение позволяет скачивать сразу всю папку или весь диск.

**Версия:** 1.0.2 Beta  
**Браузеры:** Яндекс Браузер и Chromium-совместимые  
**Разработчик:** sakurajzx

---

## ✨ Возможности

- **Скачивание всех файлов** из папки одной кнопкой.
- **Выборочное скачивание** нескольких выделенных файлов. - пока не докодил
- **Менеджер загрузок** с отображением скорости, прогресса и оставшегося времени.
- **Одновременное скачивание** нескольких файлов.
- **История загрузок** с возможностью очистки.
- **Светлая, тёмная и настраиваемая темы** оформления.
- **Гибкие настройки** расположения кнопок, папки сохранения и уведомлений.
- **Поддержка ZIP-архивов** с некоторыми ограничениями. - до 350мб

## 📥 Установка 

### Шаг 1. Скачайте расширение

1. На этой странице GitHub найдите зелёную кнопку **Code**.
2. Нажмите на неё.
3. Выберите **Download ZIP**.
4. Дождитесь загрузки архива на компьютер.

### Шаг 2. Распакуйте архив

1. Найдите скачанный ZIP-файл в папке «Загрузки».
2. Нажмите на него правой кнопкой мыши.
3. Выберите **«Извлечь всё»**.
4. Переместите распакованную папку в удобное место, например в «Документы». Я советую закинуть сразу в \C, чтоб случайно не удалить.

**Важно:** не удаляйте и не перемещайте папку после установки. Браузер будет использовать файлы расширения из неё.

### Шаг 3. Откройте настройки расширений

1. Запустите **Яндекс Браузер**.
2. Скопируйте этот адрес:

   `browser://extensions`

3. Вставьте его в адресную строку браузера и нажмите Enter.
4. Включите **«Режим разработчика»**. (Находится сверху справа)

### Шаг 4. Установите расширение

1. Нажмите **«Загрузить распакованное расширение»**.
2. Найдите папку, которую распаковали на втором шаге.
3. Выберите папку, внутри которой находится файл `manifest.json`.
4. Подтвердите выбор.

Готово! 🎉 Расширение установлено.

Если значок расширения не появился на панели браузера, откройте меню расширений и закрепите **Yandex Disk Downloader**.

## 🚀 Как пользоваться

### Скачать все файлы

1. Откройте нужную папку на Яндекс Диске.
2. Найдите кнопку **«Скачать всё»** в нижней правой части страницы.
3. Нажмите на неё.
4. Выберите нужный способ скачивания, если расширение предложит выбор.
5. Следите за процессом в окне загрузок.

### Скачать только определённые файлы - не работает вроде

1. Откройте папку с файлами.
2. Удерживайте клавишу **Ctrl** и выделите нужные файлы мышкой.
3. Для выделения последовательности файлов можно использовать **Shift**.
4. Нажмите **«Скачать выбранное»**, когда расширение распознает выделение.

Будут скачиваться только выбранные элементы.

### Посмотреть процесс скачивания

Нажмите на значок расширения в верхней части браузера.

Здесь можно посмотреть прогресс загрузок и открыть полноценный менеджер.

## 🎨 Настройки

В настройках расширения можно изменить:

- Тему оформления и собственные цвета.
- Количество одновременно скачиваемых файлов.
- Папку для сохранения загрузок.
- Способ скачивания: отдельные файлы или ZIP.
- Расположение кнопок на странице Яндекс Диска.
- Отображение прогресса и уведомлений.

Настройки сохраняются автоматически.

## 🔄 Как обновить расширение

1. Скачайте новую версию проекта с GitHub.
2. Распакуйте архив.
3. Замените файлы в папке установленного расширения новыми.
4. Откройте `browser://extensions`.
5. Нажмите кнопку обновления расширения.
6. Перезагрузите страницу Яндекс Диска.

## ⚠️ Известные проблемы

Расширение находится в стадии **Beta**, поэтому некоторые функции пока могут работать нестабильно.

- При скачивании ZIP иногда возникает ошибка `HTTP 500` со стороны API Яндекса.
- После изменения интерфейса Яндекс Диска выделение файлов может перестать распознаваться.
- В отдельных случаях сервер может вернуть текстовый файл с ошибкой вместо запрошенного видео.
- Возобновление прерванной загрузки зависит от браузера и сервера.

**Если ZIP не скачивается**, попробуйте выбрать скачивание отдельных файлов.

Нашли ошибку? Создайте обращение во вкладке **Issues** на GitHub, опишите проблему и по возможности приложите скриншот.

Не публикуйте токены авторизации и ссылки на личные файлы.

## 🔒 Конфиденциальность

Исходный код расширения открыт для просмотра. Для работы с Яндекс Диском используются запросы к его API.

Настройки и история загрузок хранятся в браузере. Для доступа к личным файлам может потребоваться дополнительная авторизация.
