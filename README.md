# Yandex Disk Downloader — by sakura

**Версия 1.0.2 (тестовая)**. Расширение для Яндекс Браузера / Chromium (Manifest V3), без Python и сторонних серверов.

## Установка / обновление

1. **Остановите старые загрузки**, если они ещё идут. Скачанные видео не удаляются.
2. Распакуйте `Yandex_Disk_Downloader_v1.0.2.zip` в постоянную папку. При обновлении предыдущей версии можно **заменить файлы в прежней распакованной папке**, чтобы сохранить ID расширения и историю. Не загружайте ZIP напрямую.
3. Откройте `browser://extensions`, включите режим разработчика.
4. Если расширение уже установлено, нажмите **«Обновить»/иконку перезагрузки** на его карточке; иначе **«Загрузить распакованное расширение»**, укажите папку с `manifest.json`.
5. Обновите вкладку Яндекс Диска **Ctrl+F5**. По умолчанию **«Скачать всё» справа снизу**. Чтобы видеть кнопки возле «Сохранить на Яндекс Диск», выберите в **Менеджер → Настройки → Расположение кнопок** вариант **«Рядом…»** или **«Оба варианта»**. При выделении файлов дополнительно появляется кнопка **«Выбранное (N)»**.

## Работа с файлами

- «Скачать всё» — загружает всю текущую папку в `Загрузки / <настроенная папка> / <название папки Яндекса>`. При включённой опции вложенные папки сохраняют структуру.
- «Выбранное» — только элементы, выделенные стандартными средствами Яндекс Диска (Ctrl, Shift). Если разметка сайта не позволяет надёжно определить выделение, расширение **откажется** от загрузки, а не запустит скачивание всей папки.
- В режиме **ZIP** вся папка запрашивается на сервере Яндекса, а произвольное выделение общим объёмом **до 350 МБ** архивируется локально. Вкладку локальной сборки ZIP не закрывайте до окончания.
- Очередь одновременно загружает от **1 до 10** файлов. При значении больше 5 показывается предупреждение о возможных ошибках.
- **Остановить всё**, **Очистить завершённые**, **Очистить ошибочные и отменённые** доступны в менеджере и popup; история поддерживает индивидуальную паузу/отмену/повтор.
- Настройки сохраняются **автоматически**. Поддерживаются системная, светлая, тёмная и кастомная темы с выбором цветов; несколько способов отображения прогресса одновременно, показ скорости и примерного времени.
- Выбранные в настройках смещения кнопок `offsetX / offsetY` задаются в пикселях; верхние кнопки привязаны к `.action-buttons .save-button_save` на Яндекс Диске. Если кнопку сайта найти нельзя, показываются рядом с панелью Яндекса.
- Переходы светлой, тёмной и кастомной тем **анимированы** (кроме системной настройки уменьшения движения).

## Совпадающие файлы / диалог

Если расширение обнаруживает **завершённую загрузку того же целевого имени в своей истории**, появляется диалог на всю операцию:

- **Заменить** — перезаписывать совпадающие файлы.
- **Переименовать новые** — браузер подбирает уникальные имена.
- **Отмена** — не запускать операцию.

**Ограничение Chromium:** расширения **не могут заранее проверить наличие произвольного файла на диске**. Если файл существует, но отсутствует в истории расширения, его автоматически переименуют (`uniquify`), чтобы не перезаписать. `saveAs:false` не открывает диалог каждый раз из-за конфликта; но **глобальная настройка Яндекс Браузера «Всегда спрашивать место скачивания» может по-прежнему открывать окно**. В таком случае отключите её в настройках браузера. Абсолютный путь Windows задавать через стандартный API загрузок нельзя.

## Исправление .txt вместо .mov / .mp4

- Загрузка дополнительно проверяет тип и размер ответа сервера, чтобы вместо видео не сохранялся короткий текст ошибки.
- Для загрузок расширения добавлена подсказка правильного целевого имени и расширения (`chrome.downloads.onDeterminingFilename`).
- Если скачанный файл окажется заметно меньше размера из метаданных Яндекса, задача получает **статус «Ошибка»**, а не ложный «Готово».
- Исторические `.txt` из старой версии не переименовываются автоматически: они могут быть ошибочными 39-байтовыми ответами, а не настоящими видео. Не надо просто менять им расширение на `.mov`.

Если ошибка повторяется, откройте «Менеджер → История» и сообщите текст ошибки и имя одного файла. Без проверки реального сервера нельзя гарантировать, что любой файл скачивается корректно.

## Личный/чужой с доступом Диск

Публичные ссылки `/d/...` доступны без аккаунта. Для личного Диска (`/client/disk/...`) и добавленных в личный Диск общих папок требуется OAuth-токен **только на чтение** (`cloud_api:disk.read`). Укажите его в настройках. Пароли в расширение не вводятся. Сохранённый токен не отображается и хранится локально. Для прямых ссылок на некоторые корпоративные общие ресурсы поддержку API нужно проверять отдельно.

Документация: https://yandex.ru/dev/disk/rest/ . Расширение не обходит запрет владельца на скачивание или ограничение доступа.

## Поддержка состояния после перезапуска

Менеджер использует системный API загрузок браузера и хранит задачи в локальном хранилище. Открытое окно popup не нужно держать во время скачивания. **История и очередь сохраняются**, однако если браузер/Windows полностью прервали загрузку, способность продолжить с того же байта зависит от Яндекса и Chromium. Иногда потребуется «Повторить», то есть начать файл заново.

## Проверки и оговорки

Проверены JavaScript-синтаксис файлов, логика выбора файлов и повторных загрузок с имитированными API, а также работа интерфейса/автосохранения с имитированным фоном в Chromium. **Сквозная проверка установленного расширения с настоящим Яндекс Диском на компьютере пользователя не выполнена**. В версии 1.0.2 выделение проверено в Chromium на имитации HTML, предоставленного пользователем: у карточек `.listing-item[aria-selected="true"]` извлекается имя из `.listing-item__title[aria-label]`; Ctrl-выделение двух карточек передало только два имени. HTML-снимок пользователя был без выделенных карточек, поэтому настоящее поведение Яндекса при Ctrl/Shift всё ещё требует проверки на живой странице.

Неофициальное расширение. Исходный код доступен. Нет телеметрии или стороннего сервера разработчика.

## Изменения v1.0.2

- По умолчанию «Скачать всё» размещена **справа снизу**; на обновлении с 1.0/1.0.1 прежний вариант «рядом» один раз переводится на новое значение по умолчанию. Пользовательский выбор после обновления сохраняется.
- Верхняя привязка теперь опирается на `.action-buttons__button_save` / `.save-button_save` и на размеры настоящего элемента.
- Распознавание Ctrl/Shift выделения исправлено под присланную разметку `.listing-item[aria-selected="true"] .listing-item__title[aria-label]`. Передача в очередь проверена на тестовом HTML.
- «Скачать всё» **никогда не превращается** в «Выбранное». При наличии выделения появляется отдельная кнопка «Выбранное (N)».
- Цвета и панели в popup / менеджере / виджете страницы плавно переходят между темами.

При неполадке с выделением пришлите HTML одного именно **выделенного** элемента через DevTools (Inspect): пользовательский снимок 1.0.2 показывал только `aria-selected="false"`, а DOM выбранной карточки может отличаться.
